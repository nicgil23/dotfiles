# Special Commands
- The agent can take screenshots globally using the `grim` and `slurp` commands.
# Global Git Constraints
- NEVER run `git commit`, `git push`, `git pull`, `git checkout`, `git switch`, or `git reset`.
- You are only allowed to inspect git status using read-only commands: `git status`, `git diff`, or `git log`.
- All commit creation, branching, and remote synchronization must be left entirely to the human developer.
